位置看得到什麼安全重點

          
            
瀏覽器 DevToolsURL、Method、Request Payload、Response不要把密碼存在 localStorage；正式站必須 HTTPS。

            
網路中間人若 HTTPS：通常只能看到 IP、Port、封包大小、部分握手資訊HTTP 明文會暴露帳號密碼；HTTPS 可保護 Header 與 Body。

            
Nginx / API Gateway解密後完整 HTTP Request做 Rate Limit、WAF、Log Masking、IP 黑白名單。

            
Backend帳號、密碼、驗證碼、Header、Cookie密碼只拿來比對 bcrypt / argon2 hash，不存明文。

            
DatabaseuserId、passwordHash、role、status查詢需參數化，避免 injection；敏感欄位加密或遮罩。
