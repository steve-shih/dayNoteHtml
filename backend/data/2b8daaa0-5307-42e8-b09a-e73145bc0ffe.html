6. this / super：自己與父類別

this

指目前這個物件本身。

class Cat {
  String name;
  Cat(String name) {
    this.name = name;
  }
}

super

指父類別，用來呼叫父類別建構子或方法。

class Animal {
  Animal(String name) {}
}

class Cat extends Animal {
  Cat() {
    super("咪咪");
  }
}

8. abstract / interface：抽象類別與規格書

abstract class

可以有欄位、一般方法、抽象方法。適合「同一類家族，有共同基底」。

abstract class Animal {
  abstract void speak();
  void eat() { }
}

interface

偏向能力規格。適合「不同類別都可以具備同一能力」。

interface Flyable {
  void fly();
}

class Bird implements Flyable {
  public void fly() {}
}
比較abstract classinterface
用途父類別骨架能力規格
可否有狀態可以有欄位通常不放 instance 狀態
繼承數量Java 只能 extends 一個Java 可 implements 多個
實務例子BaseService、AbstractRepositorySerializable、Comparable、Runnable
