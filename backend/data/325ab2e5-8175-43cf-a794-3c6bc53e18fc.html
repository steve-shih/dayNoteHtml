🪐 Antigravity 官方額度查詢
方法 1 (GUI 查詢)： 點選右上角 ⚙️ Settings → 進入 Advanced Settings → 點選 Models，即可看見各模型的剩餘額度與重置時間。
方法 2 (CLI 查詢)： 在終端機/ Agent 對話框中輸入命令 /credits 即可開啟即時額度面板。
💻 VS Code Copilot 額度查詢
方法 1 (狀態列)： 點擊 VS Code 右下角的 Copilot 圖示，即可直接看見目前額度狀態。
方法 2 (命令面板)： 按 Cmd+Shift+P 搜尋 Copilot: Show Usage。
方法 3 (Web 查詢)： 開啟瀏覽器造訪 github.com/settings/copilot。

在本機終端機中，輸入啟動指令 claude。
