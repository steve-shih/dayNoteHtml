DevOps Dashboard 實戰記憶圖鑑

① 整體故障判斷流程圖

記憶口訣： CPU → Memory → Disk → Network

② CPU 像餐廳廚師

現象指標建議值
正常CPU Usage< 60%
忙碌CPU Usage60~80%
塞車CPU Usage> 80%
CPU搶不到Load Average大於 CPU Core

③ Memory 像辦公桌

  • Memory > 85% 持續 10 分鐘告警
  • Swap > 10% 開始調查
  • OOM Killer 出現立即告警

④ Disk IO 像高速公路

指標意思告警
Disk Usage硬碟容量>80%
IO WaitCPU在等硬碟>10%
Read Latency讀取延遲>20ms
Write Latency寫入延遲>20ms

⑤ Network 像高速公路收費站

指標觀察現象
Bandwidth流量是否爆滿
Packet Loss封包遺失
Latency延遲變高
Connection Count是否遭受攻擊

⑥ Kubernetes 必看 Dashboard

層級必看指標
NodeCPU、Memory、Disk
PodRestart Count
DeploymentAvailable Replicas
Ingress5xx Error
ServiceResponse Time

⑦ SRE 黃金四指標 (Golden Signals)

指標記憶方式
Latency慢不慢
Traffic多人不多人
Error有沒有壞
Saturation快不快爆掉

口訣： 慢、人、壞、爆
