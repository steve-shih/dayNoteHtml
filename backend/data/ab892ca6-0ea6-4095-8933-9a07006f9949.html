系統設計方法總覽 × 動態決策圖產生器

先把 Design Pattern、SOLID、DDD、BDD、TDD、SDD、架構模式、分散式模式、資料模式、前端模式全部放在同一張知識地圖，再用問題引導你選出大致方向。

一、設計系統前，先知道有哪些工具箱

不要一開始就問「我要用哪個 Pattern？」比較好的順序是：先判斷問題種類，再選設計方法。下面是完整工具箱。

1. 設計原則

Principles
SOLID、DRY、KISS、YAGNI、Separation of Concerns、Law of Demeter、Composition over Inheritance、高內聚低耦合。

2. 建立型 Pattern

Creational
Factory Method、Abstract Factory、Builder、Prototype、Singleton。解決「物件怎麼建立」的問題。

3. 結構型 Pattern

Structural
Adapter、Bridge、Composite、Decorator、Facade、Flyweight、Proxy。解決「物件怎麼組合」的問題。

4. 行為型 Pattern

Behavioral
Strategy、Observer、State、Command、Chain、Template、Mediator、Iterator、Memento、Visitor、Interpreter。

5. 架構模式

Architecture
MVC、MVP、MVVM、Layered、Three-Tier、Clean、Hexagonal、Onion、Modular Monolith、Microservices、CQRS、Event Sourcing、EDA、SOA、Serverless、BFF、API Gateway。

6. 領域設計

Domain
DDD、Event Storming、Bounded Context、Ubiquitous Language、Entity、Value Object、Aggregate、Repository、Domain Service、Application Service、Specification、Saga、Policy。

7. 開發與驗證方法

Process
TDD、BDD、ATDD、SDD、CI/CD、Code Review、Pair Programming、Trunk-Based Development、Git Flow。

8. 分散式與韌性模式

Distributed
Message Queue、Pub/Sub、Webhook、Outbox、Inbox、Retry、Circuit Breaker、Bulkhead、Rate Limiting、Idempotency、Distributed Lock、Service Discovery、Load Balancing、Cache Aside。

9. 資料設計模式

Data
ER Model、Normalization、Denormalization、Index Design、Read/Write Model、Repository、Unit of Work、Data Mapper、Active Record、Audit Log、Soft Delete、Snapshot、Temporal Table、Sharding、Partitioning。

10. 前端 / UI 模式

Frontend
Component-Based、Container/Presentational、Flux、Redux、Hooks、Compound Component、Render Props、State Machine UI、Atomic Design、Design System。

11. API 與整合模式

Integration
REST、GraphQL、gRPC、Webhook、BFF、API Gateway、Backend for Frontend、Contract Testing、Versioning、Pagination、Idempotency Key。

12. 觀測與維運模式

Ops
Logging、Metrics、Tracing、SLO/SLI/SLA、Alerting、Blue-Green、Canary、Feature Flag、Rollback、Runbook。
